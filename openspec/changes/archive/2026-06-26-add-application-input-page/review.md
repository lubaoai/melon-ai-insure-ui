# 品質レビュー

## 1. 境界条件

**ステータス**：⚠️ 警告

**発見事項**：
- 郵便番号の桁数（7桁）・電話番号の桁数（10〜11桁）のフォーマットバリデーションがspecに明記されていない
- 生年月日の入力範囲（過去何年分〜現在）が未定義
- 氏名・氏名カナの最大文字数が未定義（HTMLではmaxlength=40/99等）
- 階数入力の最大値（maxlength=2なので99階まで）が未定義
- 契約希望日の最小日付（申込日の翌日以降または8日後以降）のバリデーションが未定義

**提案**：
- 各フィールドの最大文字数・フォーマット要件を実装時にHTMLに合わせて設定する
- 契約希望日の最小日付バリデーションは非目標（API連携なし）のため、フォーマットチェックのみとする

## 2. ロールバック方案

**ステータス**：✅ 合格

**発見事項**：
- 本変更は新規ページの追加と既存ページのナビゲーション更新のみであり、データ移行やAPI変更を伴わない
- ロールバックは新規ファイルの削除とルート定義の削除、意向確認画面の「次へ」ボタンをコンソールログに戻すことで対応可能
- 既存のデータ構造・インターフェースへの破壊的変更はない

**提案**：
- 特になし。新規追加のみの変更のためロールバックリスクは低い

## 3. テストカバレッジ

**ステータス**：⚠️ 警告

**発見事項**：
- 7セクションの表示シナリオは網羅されているが、条件付き表示のテストシナリオが不足している
  - 法人選択時のフィールド表示/非表示のテスト
  - 契約者と異なる選択時の居住者詳細フィールドのテスト
  - 同居人あり選択時の同居人追加・最大5名制限のテスト
  - 続柄「その他」選択時の備考フィールドのテスト
- 住居の所在地の「契約者と同じ」コピーボタンのテストシナリオが定義されているが、実装の複雑さに対する考慮が必要

**提案**：
- 条件付き表示のテストを各セクションコンポーネントのテストに追加する
- 同居人追加・削除のテストはCoResidentSectionのテストに含める

## 4. 後方互換性

**ステータス**：✅ 合格

**発見事項**：
- 既存のインターフェース変更はIntentConfirmationPageのonNextコールバックの実装変更のみ
- IntentionSectionのpropsインターフェース（canProceed, onCustomerNumberChange, onBack, onNext）は変更なし
- 新規コンポーネントは既存のデザインシステム（Tailwind CSS カスタムプロパティ）を利用するため、既存スタイルへの影響はない
- ルーティングに新規パスを追加するのみで、既存パスの変更はない

**提案**：
- 特になし。後方互換性への影響は最小限

## 全体評価

**分割方向の提案**：
以下のタスクグループに分割する：

1. **インフラ設定**：ルーティング追加、意向確認画面の遷移更新
2. **基本セクション実装（3セクション）**：ContractDateSection、ContractCourseSection、HousingOverviewSection
3. **契約者セクション実装**：ContractorInfoSection（条件付き表示あり）
4. **住所・居住者セクション実装（3セクション）**：ResidenceLocationSection（コピーボタン付き）、PrimaryResidentSection（条件付き表示あり）、CoResidentSection（動的リスト付き）
5. **ページ統合**：ApplicationInputPage の実装、全セクション統合、活性制御
6. **テスト・調整**：ルーティングテスト更新、統合テスト、最終調整

**優先順位付け**：
1. インフラ設定 → 他のタスクの前提
2. 基本セクション → 条件付き表示なしの単純なセクションを先に実装
3. 契約者セクション → 条件付き表示（法人/個人）の実装パターンを確立
4. 住所・居住者セクション → コピーボタン・動的リストなど複雑な機能を含む
5. ページ統合 → 全セクション実装後に統合
6. テスト・調整 → 最後に実施

**粒度の基準**：
- 条件付き表示なしのセクションは1タスクにまとめる可能性あり（ただしtasks.mdでは各1タスクとする）
- 条件付き表示ありのセクションは1タスクとする（表示テスト+条件切替テストを含む）
- CoResidentSectionは動的リストの実装が複雑なため1タスクとする
- ページ統合は1タスクにまとめる（セクションの配置と活性制御の実装）
