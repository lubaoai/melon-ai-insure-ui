## なぜ

現在のUIは機能検証を目的としたスキャフォールド段階に留まっており、Tailwind CSSのデフォルトテーマを使用しているためブランドアイデンティティを表現できていない。また、統一されたアイコン体系やインタラクションデザインが不足し、カード・ナビゲーションの表現も単調である。製品品質のユーザー体験を実現するため、メロン少額短期保険の契約画面を参照して、ブランドカラー・アイコンシステム・アニメーションを含むビジュアルデザイン全体のアップグレードが必要である。

## 変更内容

- **ブランドカラーシステムの導入**: メロン少額短期保険のマゼンタ（#b40081）をプライマリカラーとし、オレンジ（#FF8B2C）をCTAカラー、アンバー（#E99606）を警告カラーとするデザイントークンを定義・適用する
- **タイポグラフィの設定**: ヒラギノ／Meiryoベースのフォントスタックと、15pxベースのサイズスケールを導入する
- **アイコンシステムの導入**: React Icons（またはLucide React）を導入し、ナビゲーション・カード・ボタンに統一されたアイコンを適用する
- **ホームページの再設計**: メロン少額短期保険の契約画面（page01）を参照し、ステップナビゲーション付きのホームページを実装する。保険商品一覧をカード形式で表示し、ブランドカラーとインタラクションを適用する
- **ナビゲーションバーの新設**: マゼンタのボーダーを持つヘッダーと、6段階のステップインジケーターを実装する
- **フッターの新設**: マゼンタ背景のブランドフッターを追加する
- **コンポーネントのスタイルアップグレード**: ボタン・フォーム・カードにブランドカラー、シャドウ、ボーダーラディウスを適用する
- **インタラクション・アニメーションの追加**: ホバーエフェクト、トランジション、ローディングオーバーレイを追加する

## 機能一覧

### 新規機能
- `brand-tokens`: ブランドカラー、タイポグラフィ、スペーシング、シャドウのデザイントークン定義とTailwind CSSへの統合
- `icon-system`: React Iconsの導入と、ナビゲーション・カード・ボタンで使用するアイコンマッピングの定義
- `header-navigation`: マゼンタボーダー付きヘッダー、ロゴエリア、ステップインジケーターを含むナビゲーションコンポーネント
- `home-page-redesign`: メロン少額短期保険のpage01を参照したホームページの再設計（ステップナビ、商品カードグリッド、CTAボタン、Q&Aサイドバー）
- `brand-footer`: マゼンタ背景のブランドフッターコンポーネント
- `interaction-animations`: ホバーエフェクト、トランジション、ローディングオーバーレイのインタラクションデザイン
