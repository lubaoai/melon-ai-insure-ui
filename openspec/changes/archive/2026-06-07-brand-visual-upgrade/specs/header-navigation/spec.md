## ADDED Requirements

### Requirement: ヘッダーコンポーネントの実装

システムは白色背景にマゼンタ（#b40081）の4px下部ボーダーを持つヘッダーコンポーネントを実装しなければならない（MUST）。ヘッダーはロゴエリア（左寄せ）とお問い合わせ電話番号エリアを含まなければならない（MUST）。ヘッダーはコンテンツ最大幅（1024px）内に制約され、中央揃えで配置されなければならない（MUST）。

#### Scenario: ヘッダーがブランドカラーで表示される
- **WHEN** ページがレンダリングされる時
- **THEN** ヘッダー下部に4pxのマゼンタボーダーが表示されること

#### Scenario: ロゴが表示される
- **WHEN** ヘッダーがレンダリングされる時
- **THEN** 左側にブランドロゴ（テキストまたは画像）が表示されること

#### Scenario: 電話番号が表示される
- **WHEN** ヘッダーがレンダリングされる時
- **THEN** ロゴの右側にお問い合わせ電話番号が表示されること

### Requirement: ステップナビゲーションコンポーネントの実装

システムは6段階の水平ステップインジケーターを実装しなければならない（MUST）。ステップは以下の順序で表示される:
1. ①重要事項同意
2. ②意向確認
3. ③申込内容入力
4. ④申込内容確認
5. ⑤決済手続き
6. ⑥申込完了

現在のステップはマゼンタ背景（#b40081）に白テキストで表示し（MUST）、非アクティブステップはライトピンク背景（#ffe5f7）にダークグレーテキストで表示しなければならない（MUST）。各ステップ間にはChevronRightアイコンをセパレーターとして表示しなければならない（MUST）。ステップはクリック不可とし、進行位置の表示のみを行わなければならない（MUST）。

#### Scenario: 現在のステップがハイライト表示される
- **WHEN** ステップ1がアクティブな時
- **THEN** ステップ1がマゼンタ背景・白テキストで表示され、他のステップはライトピンク背景・ダークグレーテキストで表示されること

#### Scenario: ステップセパレーターが表示される
- **WHEN** ステップナビゲーションがレンダリングされる時
- **THEN** 各ステップの間にChevronRightアイコンが表示されること（最後のステップの後には表示しない）

#### Scenario: ステップがクリック不可
- **WHEN** ユーザーがステップをクリックする時
- **THEN** ページ遷移や状態変更が発生しないこと

#### Scenario: 境界外のステップ番号が指定された場合
- **WHEN** 現在ステップとして0または7が指定された時
- **THEN** 最も近い有効なステップ（1または6）にクランプされて表示されること
