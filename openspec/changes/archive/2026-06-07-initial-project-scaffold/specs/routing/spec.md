## ADDED Requirements

### Requirement: React Router 7 によるルーティング設定
react-router-dom v7を用いてルーティングを設定し、URLパスに対応するページコンポーネントをレンダリングすること。ルーター設定は `src/router/` ディレクトリに集約すること。

#### Scenario: ルートパスへのアクセス
- **WHEN** ユーザーが `/` にアクセスしたとき
- **THEN** HomePage コンポーネントがレンダリングされる

#### Scenario: 存在しないパスへのアクセス
- **WHEN** ユーザーが `/nonexistent-path` など定義されていないパスにアクセスしたとき
- **THEN** 404ページがレンダリングされ、ページが見つからない旨が表示される

### Requirement: ルーター構成の拡張性
新しいページの追加が容易なルーター構成にすること。ルーター定義を `src/router/` に集約し、ページ追加時にルーター設定ファイルのみを変更すればよい構造にする。

#### Scenario: 新規ルートの追加
- **WHEN** 開発者が `src/router/` のルーター設定に新しいパスとコンポーネントを追加したとき
- **THEN** 追加したパスで新しいページコンポーネントが正常にレンダリングされる

#### Scenario: ルーター設定の集約
- **WHEN** プロジェクトのルーター構成を確認するとき
- **THEN** 全てのルート定義が `src/router/` ディレクトリ内に集約されている
